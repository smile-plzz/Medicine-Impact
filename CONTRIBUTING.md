# Contributing Guidelines

Thank you for your interest in contributing to the Medicine Impact Simulator!

## How to Contribute

1. **Bug Reports**: If you find a bug, please create an issue detailing the steps to reproduce it, expected behavior, and actual behavior.
2. **Feature Requests**: Have an idea for a new feature? Open an issue describing what you want to add and why it would be beneficial.
3. **Pull Requests**:
   - Fork the repository.
   - Create a new branch for your feature or bug fix (`git checkout -b feature/my-new-feature`).
   - Commit your changes with descriptive messages (`git commit -am 'Add some feature'`).
   - Push to the branch (`git push origin feature/my-new-feature`).
   - Open a Pull Request.

## Code Style
- We use standard TypeScript/React conventions.
- Use functional components and hooks.
- Style with Tailwind CSS utility classes.
- Ensure all new features are fully typed in `src/types.ts`.
